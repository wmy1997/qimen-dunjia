# 六爻 · 奇门 排盘（个人自用 PWA）

一款纯前端、免服务器的问卦排盘小程序，两套体系并存、各走各的推理逻辑：

- **六爻（纳甲筮法，默认）**：内核复用 [taibu-core](https://github.com/hhszzzz/taibu) 的 `liuyao` 域（MIT），装卦、用神、原忌仇神、应期均由内核计算，界面与解读由本项目实现。
- **奇门遁甲（时家转盘）**：排盘内核复用 [3meta](https://github.com/3metaJun/3meta)（MIT），神煞与应期规则自实现。

AI 解读由浏览器直连 DeepSeek 官方接口（BYOK，自带 Key），不经过任何第三方服务器。

## 功能

### 通用

- **问题入口**：先写问题，程序按问句类型给出「更适合六爻 / 奇门」的建议（规则判断，即时、不调模型），也可自行点卡片切换。
- **问事分类**：综合 / 事业 / 财运 / 婚姻 / 健康 / 学业 / 出行 / 官司 / 寻物，决定用神取法。
- **AI 解读**：DeepSeek 流式解读（深度思考 + 白话建议），严格依据排盘数据，按「取用神 → 看旺衰 → 看动静 → 看生克 → 定吉凶 → 定应期 → 给建议」的顺序断卦。
- **历史记录**：自动保存最近 50 条（含体系、卦象、六爻值、解读），可回看、重算、导入导出。
- **PWA**：可安装到手机桌面，离线可用（需 HTTPS 或 localhost）。

### 六爻

- **摇卦三种方式**：逐爻摇（三枚铜钱，正统）、一键摇完（便捷）、手动录入（自己在外摇过）。
- **装卦**：六神、六亲、纳甲、五行、阴阳爻、动爻（老阳○ / 老阴×）、世应、伏神、变爻，附月建日辰生克与旺衰证据。
- **用神**：按问事类别取六亲；婚姻类可选性别（男取妻财、女取官鬼），用神两现时给出候选与取舍说明。
- **原神 / 忌神 / 仇神**：按用神自动列出，供生克分析。
- **应期推算**：内核按值日值月、冲空填实等给出触发条件与依据。
- **卦体特征**：六冲、六合、反吟、伏吟、三合局、卦身、卦神煞，卦辞与象辞可展开。

### 奇门

- **正时起局**：点击「开始排盘」自动以当前时刻起局（节气＋阴阳遁＋局数由起局时刻决定）。
- **九宫盘**：八神 / 九星 / 八门 / 天地盘干 / 暗干 / 地支 / 标记（值符值使 / 空亡 / 驿马 / 击刑 / 门迫 / 入墓 / 吉凶格）。
- **用神**：每类 4 个用神落宫，附星门旺衰、格局、干应。
- **神煞**：天乙贵人 / 天德 / 月德 / 国印 / 文昌 / 禄神 / 华盖 / 桃花 / 羊刃（日干、日支、月支、年干起）。
- **应期推算**：伏吟/反吟与内外盘定远近尺度，按旬空填实、马星、逢冲以合、逢合以冲、日干入墓、三合缺支、旺衰生扶的优先级链定应期支，并给值使宫数事期。
- **格局汇总**：五不遇时、门迫门制、吉格、凶格。

## 文件结构

- `index.html` / `style.css` —— 页面与样式
- `app.js` —— 体系切换、奇门渲染、历史、设置、AI 流式解读
- `liuyao.js` —— 六爻界面、摇卦、装卦渲染、应期与解读 prompt
- `rules.js` —— 奇门神煞与应期规则引擎（自实现，表口径参考 atopx/qimen 的 MIT 神煞表）
- `vendor/3meta.min.js` —— 奇门排盘内核（v2.6.0，MIT）；已按业界主流口径打两处补丁：值使门从「真实旬首宫」起数、落中五一律寄坤二（原版为中五→坤二起数、阳遁落中五→艮八），其余逻辑未改动，补丁后与 taibu-core / atopx / qfdk 三库逐盘一致
- `vendor/liuyao.min.js` —— 六爻内核（taibu-core `liuyao` 域打包，MIT；含同步 sha256 shim 以替代 Node `crypto`）
- `manifest.json` / `sw.js` —— PWA 清单与离线缓存
- `icon.svg` / `icon-192.png` / `icon-512.png` —— 图标
- `README.md` / `交叉验证报告.md` / `项目规划书.md` —— 文档
- `tools/` —— 六爻内核打包脚本（`build-liuyao.sh` + `liuyao-entry.js` + `crypto-shim.js`），仅开发用

> 部署只需页面 / 内核 / PWA 文件；`node_modules`、`package.json`、`tools/`、`_*.js` 为开发用，可不上传。

## 部署（免费静态托管，推荐）

### 方式一：GitHub Pages

1. 把本目录所有文件推到 GitHub 仓库根目录。
2. 仓库 Settings → Pages → Source 选 `main` 分支根目录 → Save。
3. 稍等几分钟，访问 `https://<用户名>.github.io/<仓库名>/`。
4. 手机浏览器打开 → 「添加到主屏幕」，即可作为 App 使用。

### 方式二：Vercel / Netlify

1. 登录 vercel.com 或 netlify.com，用 GitHub 导入仓库。
2. 框架选「Other / 静态站点」，构建命令留空，输出目录填 `.`（根目录）。
3. 部署后获得 `https://xxx.vercel.app`（自带 HTTPS）。

### 本地预览

```bash
python3 -m http.server 8000   # 访问 http://localhost:8000（Service Worker 可注册）
```

> 直接双击 `index.html`（file://）也能排盘，但 Service Worker 不注册、无法安装 PWA。

## 使用

1. 点 ⚙「设置」，填入 DeepSeek API Key（在 platform.deepseek.com 创建，仅存本机 localStorage）。
2. 写问题，按提示或自行选择六爻 / 奇门；补充现状（选填）。
3. 六爻：摇六爻成卦（或一键摇完）；奇门：点「开始排盘」。
4. 选「问事」分类查看用神，点「🔮 AI 解读」获取白话建议。
5. 点「📜 历史」回看历史问卦。

> **模型选择**：默认 `v4-pro`（深度思考，解读更准，推荐）；`flash` 更省额度，适合高频简单提问。

## 说明

- **体系差异**：六爻一事一占、长于断具体事成败与应期；奇门以时空格局见长，适合比选项、看方位与整体态势。程序在两套体系上方各有一句说明，并按问句给出倾向建议。
- **起局口径**：奇门为正时起局——以点击排盘时刻的节气定阴阳遁与局数，四柱由该时刻决定；六爻以成卦时刻的月建日辰断旺衰。问题与现状只参与解读、不参与排盘。
- **隐私与费用**：API Key 仅存本机 localStorage，浏览器直连 `api.deepseek.com`；费用从你的 DeepSeek 余额扣除。
- **排盘内核**：[3meta](https://github.com/3metaJun/3meta) 与 [taibu-core](https://github.com/hhszzzz/taibu)（均 MIT License）。
- **验证**：奇门起局 / 用神格局 / 解读建议 / 神煞应期、六爻装卦与用神，均已交叉验证（金标准向量 + 独立库对照 + 规则链全量扫描），详见 `交叉验证报告.md`。
